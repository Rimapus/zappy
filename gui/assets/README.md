# GUI assets

The GUI art, music and font files are not included in this repository. The terrain
and character art comes from the Sprout Lands asset pack by Cup Nooble. Its free
license allows non-commercial use with credit but not redistribution.

The GUI source loads these files, relative to the `gui/` directory:

```text
assets/Fonts/8bitOperatorPlus-Regular.ttf
assets/Music/main.ogg
assets/Player/idle.png
assets/Player/walk.png
assets/Player/death.png
assets/Player/hurt.png
assets/Egg/egg.png
assets/UI/panel.png
assets/Ressources/food.png
assets/Ressources/linemate.png
assets/Ressources/deraumere.png
assets/Ressources/sibur.png
assets/Ressources/mendiane.png

assets/Props/Flower.png
assets/Props/Water_Lily/water_lily_1.png
assets/Props/Bush.png
assets/Props/Stone/stone.png
assets/Props/Rock/rock.png
```

- Sprout Lands asset pack: https://cupnooble.itch.io/sprout-lands-asset-pack;
  not included.
- 8-bit Operator+ font by GrandChaos9000 (GCPD): SIL Open Font License 1.1;
  not included.
- Music track: not included. The GUI logs a warning and continues when it is
  missing.
